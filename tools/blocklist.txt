# Blocklist for the word pipeline (tools/build_dict.py). NOT shipped in the app.
#
# One regular expression per line, matched against the WHOLE normalised key:
# lowercase, accents removed (á->a, ü->u), ñ kept. Example: "maricón" -> "maricon".
#
# [hard]  removed from every list: never a level word, never a daily answer, never accepted as a bonus word.
#         Vulgar/sexual terms, slurs and insults with no common innocent meaning.
# [soft]  accepted as a bonus word only (the player typed a real word, we don't scold them), but never
#         placed in a crossword, never a daily answer. Words with an innocent meaning that are also
#         rude somewhere (coger, concha, paja, pija...), anatomy, mild insults, drugs, violence, religion-swear.
#
# Words that are harmless in Spain and vulgar in Latin America (or the reverse) go to [soft] at least:
# the audience is Spain + Latin America.
